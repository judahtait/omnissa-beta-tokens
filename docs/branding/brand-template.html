6. Rules

Do

  • Use the Omnissa gradient for the header band and the icon tile.
  • Use Outfit Light for body, Medium for titles and buttons.
  • Use dynamic light and dark pairs from the palette.
  • Keep a frosted glass surface over a soft indigo and magenta backdrop.

Do not

  • Use magenta as a default accent. It is for negative data and the gradient end.
  • Fix a light background and rely on default text color, which turns white in dark mode.
  • Use Apple's logo, or copy an existing Omnissa product mark.
  • Put tokens, tenant names or session data in screenshots.
